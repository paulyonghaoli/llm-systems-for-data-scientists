# My progress

Mark any lesson with the control at the top of the page — **Reading**, **Done**,
or **Needs more time** — and this page adds it up.

## Where this is stored

In your browser's local storage, on this device, and nowhere else. There is no
account, no server and no analytics attached to it — the site is a folder of
static files, so there would be nothing to send it to even if it wanted to.

Two consequences worth knowing:

- **It does not follow you between devices or browsers.** Progress marked on a
  laptop will not appear on a phone.
- **Clearing site data clears it.** So does a browser set to wipe storage on
  exit.

If you are working through a whole course, use **Export JSON** occasionally.
The importer merges by timestamp and keeps the newer mark for each page, so
importing an old export cannot undo work you have done since.

## Why not cookies

A cookie is sent to the server with every single request, which would be
pointless here — nothing on the server would read it — and it is that
transmission which makes cookie banners necessary in the first place. Local
storage stays in the browser, so there is nothing to disclose and nothing to
ask permission for.
